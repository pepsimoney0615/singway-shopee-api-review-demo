SingWay ERP/WMS Review Environment v2

This is a review-only ERP/WMS environment for Shopee Open Platform evaluation. It demonstrates cross-platform marketplace order workflows, SKU mapping, inventory control, inbound receiving, picking, logistics tracking, staff efficiency, and API / import logs.

The environment uses demo and de-identified review datasets only. It is isolated from production systems and does not expose production databases, live API credentials, unmasked buyer PII, or write operations.

Security & Privacy Center

Security Notice
This review environment is read-only and isolated from production WMS systems. It does not connect to production databases, upload folders, spreadsheets, live API tokens, API keys, partner keys, or seller credentials.

Review-only account

The reviewer account is read-only and only opens review environment pages.

Masked buyer information

Buyer names, phone numbers, addresses, order numbers, logistics numbers, and marketplace records are masked, anonymized, or demo review records.

No production DB

The site is static and has no production database connection.

First phase privacy

No unmasked PII permission is requested in the first phase.

Credential handling

Token encryption is planned for production backend storage; no credential is exposed here.

Least privilege

Production API scopes are planned around the minimum required ERP/WMS workflows.

Audit logs

Import / sync and operator activity logs are part of the production design.

HTTPS deployment

Cloudflare Pages provides HTTPS for the review environment.

Official API authorization only

The system does not perform scraping, simulated login, CAPTCHA bypassing, browser automation, or unofficial data extraction. Shopee integration will only use official Shopee Open Platform authorization after approval.
