Shopee Integration

Planned integration through Shopee Open Platform official authorization. This static demo does not call the real Shopee API.

  1. Seller authorization

    Seller must authorize through Shopee Open Platform before data access.

  2. Authorization code exchange

    The backend exchanges the authorization code after redirect validation.

  3. Token handling

    Access token and refresh token handling is designed to be backend-only and scoped per shop or merchant.

  4. First phase privacy

    No unmasked PII permission requested in the first phase.
