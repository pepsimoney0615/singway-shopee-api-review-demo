Security & Privacy Center

Review-only account

The reviewer account is read-only and only opens review environment pages.

Masked PII

Buyer names, phone values and addresses are masked or reduced to city-only examples.

No production DB

The site is static and has no production database connection.

First phase privacy

No unmasked PII permission is requested in the first phase.

Credential handling

Token encryption is planned for production backend storage; no credential is exposed here.

Least privilege

Production API scopes are planned around the minimum required ERP/WMS workflows.

Audit logs

Sync and operator activity logs are part of the production design.

HTTPS deployment

Cloudflare Pages provides HTTPS for the review environment.

Official API only

No scraping, no CAPTCHA bypass and no unofficial data extraction are used.
